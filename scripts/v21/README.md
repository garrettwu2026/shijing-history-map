# TASK21 人工介紹批次

`polities.tsv` 為逐條撰寫的歷史內容，每列依序為：目錄中文名、歷史分期、首都、語言、背景、影響、年表、人物。摘要只組合本列已撰寫的背景、兩項事件及影響，不從地圖快照年份推斷史事。

`equivalent-names.json` 只列人工確認可共用歷史介紹的名稱；不以模糊比對擴展到相鄰地區、其他民族或後繼國家。`key-figures.json` 保留有把握的制度數量與確定紀年。`review-notes.json` 記錄撤回的草稿及語意修正；撤回內容不再放入可寫入批次。

```sh
python3 scripts/expand-v21.py
python3 scripts/validate-intros.py
python3 scripts/build-static.py
npm run validate
```

腳本跳過已有完整介紹的 ID，整批驗證通過後才寫入，每次最多 30 筆，原子替換資料及 `scripts/v18b-progress.json`。無新增條目時仍刷新衍生數量，但不改寫時間戳。新增內容必須先人工確認；未列入批次的政體不能理解為已完成史實審核。
