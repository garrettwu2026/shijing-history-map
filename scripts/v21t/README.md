# TASK21T 譯名與介紹批次

`batch-*.json` 是人工審核的明確 ID 對照，不作模糊比對。`profileFrom` 只用於同一歷史族群的自稱、領地標籤或拼寫變體；不能把族群支系、保留區政府或相鄰民族當成同一實體。全新撰稿使用 `profile` 保存完整欄位。

- 中文名稱沿用已審核詞彙；新譯名須另有可查核的繁體中文用例。領地標籤明示其意義，不創造新的帝國。
- `identitySource`、`researchSources`、`nameBasis` 和 `note` 留作編輯查核。介紹不含查核連結或來源標記，介面不增加來源顯示。
- 家園自稱不一律視為國號。無共同首都、中央政府或確定建國年的社群須明說；地圖快照的觀測年不是政體的建國或滅亡年。
- 新稿保留前身／後繼欄位，只有能確認目錄 ID 的直接關係才加入連結。不確定的量值省略關鍵數據欄位。

每個 manifest 最多 30 筆，整批介紹驗證通過才寫入；同步套用詞彙表至 `polities.json` 與 `names.json`。每批保存到 `scripts/v18b-progress.json`，已完成 ID 續跑不改寫。原有完整介紹不修改。

```sh
python3 scripts/expand-v21t.py scripts/v21t/batch-01.json
npm run build
npm run validate
```

`npm run validate` 的既有事件詳情 300 筆門檻保持原樣；若未通過，仍需分別執行後續驗證並如實記錄。驗證結果放在對應的 `artifacts/v21t-batch-*/`，每批進度的 `validation` 記錄檢查結果。不要將名稱數或重複標籤數當成獨立歷史國家的數量。

本工作仍以 1,500 筆完整介紹為目標；沒有達標前維持 `in-progress`。新增後續批次必須先完成名稱與史實查核，不能由待考名單直接自動翻譯。
